## 📋 개요

## 🚀 주요 기능별 사용법

### 1. 자동 로그인 및 세션 데이터 생성

#### 파일: `test_auto_login.py`

네이버 카페에 자동으로 로그인하고 세션 데이터를 JSON 파일로 저장합니다.

```bash
python test/test_auto_login.py -u "사용자명" -p "비밀번호"
```

**파라미터:**
- `-u, --username`: 네이버 아이디
- `-p, --password`: 비밀번호
- `-v, --verbose`: 상세 로그 출력

**출력 파일:**
- `naver_login_data_[timestamp].json`: 로그인 세션 데이터

**사용 예시:**
```bash
python test/test_auto_login.py -u "myid@naver.com" -p "mypassword"
```

---

### 2. 카페 댓글 자동 업로드

#### 파일: `test_cafe_comment_upload.py`

저장된 세션 데이터를 사용하여 네이버 카페에 댓글을 자동으로 업로드합니다.

```bash
python test/test_cafe_comment_upload.py \
  -j test/naver_login_data_20251024_184053.json \
  -c 12175294 \
  -a 2752532 \
  -m "댓글 내용"
```

**파라미터:**
- `-j, --json-file`: 로그인 세션 데이터 JSON 파일 경로
- `-c, --cafe-id`: 카페 ID (예: 12175294)
- `-a, --article-id`: 게시글 ID (예: 2752532)
- `-m, --message`: 댓글 내용
- `-v, --verbose`: 상세 로그 출력

**실행 예시:**
```bash
python test/test_cafe_comment_upload.py \
  -j test/naver_login_data_20251024_184053.json \
  -c 12175294 \
  -a 2752532 \
  -m "공감합니다~ 지피티가 생각 정리를 잘 도와주더라구요"
```

**성공 시 출력:**

### 3. 카페 게시글 키워드 검색

#### 파일: `cafe_keyword_search.py`

10초 + 오차 주기로 카페 게시글을 조회하여 키워드가 포함된 게시글을 찾습니다.

```bash
python test/cafe_keyword_search.py \
  -j test/naver_login_data_20251024_184053.json \
  -c 12175294 \
  -m 15 \
  -k "맥북,지피티,노트북" \
  -d 30
```

**파라미터:**
- `-j, --json-file`: 로그인 세션 데이터 JSON 파일 경로
- `-c, --cafe-id`: 카페 ID (예: 12175294)
- `-m, --menu-id`: 메뉴 ID (예: 15)
- `-k, --keywords`: 검색할 키워드들 (쉼표로 구분)
- `-d, --duration`: 검색 지속 시간 (분, 기본값: 60분)
- `-v, --verbose`: 상세 로그 출력

**실행 예시:**
```bash
# 30분간 맥북, 지피티, 노트북 키워드 검색
python test/cafe_keyword_search.py \
  -j test/naver_login_data_20251024_184053.json \
  -c 12175294 \
  -m 15 \
  -k "맥북,지피티,노트북" \
  -d 30
```

## ⚠️ 주의사항

### 1. 세션 데이터 관리
- 로그인 세션은 시간이 지나면 만료됩니다
- 정기적으로 새로운 세션 데이터를 생성하세요
- 계정별로 별도의 세션 데이터 파일을 사용하세요

### 2. 사용 제한
- 너무 빈번한 댓글 업로드는 탐지 위험을 증가시킵니다
- 자연스러운 간격으로 사용하세요
- 실제 사용자처럼 다양한 시간대에 사용하세요

### 3. 키워드 검색
- 키워드는 쉼표로 구분하여 입력하세요
- 대소문자는 구분하지 않습니다
- 부분 매칭으로 검색됩니다

## 🛠️ 문제 해결

### 자주 발생하는 오류

#### 1. 세션 만료 오류
```
❌ 세션이 유효하지 않습니다. 로그인 데이터를 갱신해주세요.
```
**해결방법:** 새로운 세션 데이터를 생성하세요
```bash
python test/test_auto_login.py -u "사용자명" -p "비밀번호"
```

#### 2. JSON 파일을 찾을 수 없음
```
❌ 오류: JSON 파일을 찾을 수 없습니다
```
**해결방법:** 올바른 파일 경로를 확인하고 먼저 로그인을 실행하세요

#### 3. API 호출 실패
```
❌ API 호출 실패: 403
```
**해결방법:** 
- 세션 데이터가 유효한지 확인
- 네트워크 연결 상태 확인
- 잠시 후 다시 시도
